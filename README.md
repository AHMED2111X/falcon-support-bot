# 🛡️ FALCON SUPPORT BOT — بوت الدعم لقناة FALCON_KERNEL_PRO

بوت تيليجرام يعمل **24/7** بدون خادم (Cloudflare Worker) أو محلياً (PowerShell).

---

## 🎯 ما يفعله البوت

| الميزة | التفاصيل |
|---|---|
| 🧹 **حذف فوري** | أي رسالة فيها **رابط** أو **معرّف تيليجرام** (`@user`) أو **رقم معرّف** (9 أرقام+) أو **سبام** ⇒ تُحذف في جزء من الثانية |
| 📋 **رد بالقالب** | رسالة المشكلة الحقيقية ⇒ يرد البوت بقالب يجمع: الموديل، إصدار أندرويد، نوع الروت، رقم FALCON، صورة الخطأ |
| ⏱️ **رسائل بطيئة** | رسالة واحدة كل **10 ثوانٍ** لكل شخص (يُضبط تلقائياً) |
| 📢 **تنبيه المشرف** | كل رسالة محذوفة تصل إليك في الخاص مع اسم المرسل وسبب الحذف |
| 🔗 **روابط المشروع** | `/links` — القناة الرسمية + حساباتك + رابط التحميل |
| 🆔 **معرّف المستخدم** | `/id` — يعطي كل شخص معرّفه الرقمي (مفيد للدعم) |

### الأوامر

| الأمر | لمن | الوظيفة |
|---|---|---|
| `/start` `/help` | الجميع | ترحيب + الإرشادات |
| `/rules` | الجميع | قواعد المجموعة |
| `/links` | الجميع | روابط المشروع |
| `/id` | الجميع | معرّفك الرقمي |
| `/slow <ثانية>` | المشرف فقط | ضبط الرسائل البطيئة (0 = تعطيل) |
| `/broadcast <نص>` | المشرف فقط | إرسال رسالة لكل المجموعة |
| `/silent on\|off` | المشرف فقط | إيقاف/تفعيل الحذف المؤقت |

## 🚀 المسار A — Cloudflare Worker (موصى به · مجاني · دائم)

### 1) أنشئ المجموعة واربطها بالقناة (في تطبيق تيليجرام)
```
القناة @FALCON_KERNEL_PRO  →  إعدادات (⚙️)  →  Discussion / النقاش
   →  Add a new group / إنشاء مجموعة جديدة
   →  الاسم:  FALCON SUPPORT  |  المستخدم: @FALCON_SUPPORT
   →  ✅ فعّل "إدارة المواضيع" (Topics) — أفضل للدعم
   →  احفظ
```
> بعد الربط: القناة ➜ Discussion متاح للمشتركين، والبوت يُضاف للمجموعة.

### 2) أضف البوت مشرفاً في المجموعة الجديدة
```
المجموعة  →  معلومات (ℹ️)  →  المشرفون  →  إضافة مشرف  →  @FALCON_VERIFY_2026_BOT
   ✅ حذف الرسائل (Delete Messages)
   ✅ تقييد الأعضاء (Restrict Members)   ← للرسائل البطيئة
   ✅ دعوة المستخدمين / المنشئ (Invite Users)  ← اختياري
```

### 3) ارفع الكود إلى مستودع الـWorker
المستودع: `https://github.com/AHMED2111X/falcon-counter-server`
```
- استبدل server.js  →  الكود الجديد (server.js + support-bot.js مدمج)
- أو أضف support-bot.js وغيّر main في wrangler.toml
- Commit على main  →  Cloudflare Workers Builds ينشر تلقائياً
```

### 4) متغيرات Cloudflare (Settings → Variables)
```
BOT_TOKEN   = 8973794542:xxxxx      (من bot_token.txt)
TG_SECRET   = كلمة سرية عشوائية طويلة
ADMIN_ID    = معرّفك الرقمي في تيليجرام
CHANNEL_ID  = -1003981458690
SLOW_MODE   = 10
LINKS_JSON  = [{"title":"...","url":"..."}, ...]
```

### 5) سجّل الـWebhook
```bash
curl -X POST "https://api.telegram.org/bot<TOKEN>/setWebhook" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://falcon-counter-server.ahmedsibero199847-0ba.workers.dev/tg/webhook/<TG_SECRET>",
    "allowed_updates": ["message","edited_message","channel_post"]
  }'
```
اختبار:
```bash
curl "https://falcon-counter-server.ahmedsibero199847-0ba.workers.dev/tg/health"
```

## ⭐ المسار B — دائم على جهازك (المعتمد حالياً)

المسار B لم يعد "تجربة" — صار **تشغيلاً دائماً** مع بحث ذاتي:

```powershell
cd C:\Users\Administrator\Desktop\FALCON_SUPPORT_BOT
powershell -ExecutionPolicy Bypass -File install_autostart.ps1
```

### ما الذي يثبّته التثبيت؟

| المكوّن | التفصيل |
|---|---|
| 🔁 **مراقب دائم** (`watchdog.ps1`) | يفحص كل 60 ثانية · يعيد تشغيل البوت فوراً إذا سقط · يمنع نسختين (تعارض 409) |
| 📌 **اختصار بدء التشغيل** | مجلد Startup ⇒ يعمل تلقائياً عند كل تسجيل دخول |
| ⏰ **مهمة مجدولة** | «عند الدخول» + «كل 5 دقائق» · إعادة تشغيل تلقائية 999 مرة كل دقيقة |
| 🔒 **ملف قفل** | `.bot.lock` يمنع تشغيل نسختين معاً |
| 📜 **تدوير السجل** | `support_bot.log` لا يتجاوز 1 ميجابايت |

### إلغاء التثبيت
```powershell
powershell -ExecutionPolicy Bypass -File install_autostart.ps1 -Uninstall
```

> ⚠️ **تنبيه**: البوت يعمل بـ long-polling ⇒ **يجب أن يبقى هذا الجهاز مُشغّلاً ومتصلاً بالإنترنت**.
> عند انقطاع الشبكة يعيد الاتصال تلقائياً. وعند إطفاء الجهاز يستأنف عند الدخول التالي.
> (لو أردت تشغيلاً بلا جهاز لاحقاً: Cloudflare Worker — راجع المسار A.)

## 🔎 ما الذي يُعتبر «سبام»؟

| النوع | أمثلة |
|---|---|
| معرّف تيليجرام | `@username` · `t.me/xxx` · `telegram.me/xxx` |
| روابط | `https://...` · `www.xxx.com` · `github.com/...` · `bit.ly/...` |
| نطاقات بلا بروتوكول | `example.com` · `xyz.io` · `site.ru` |
| معرّفات رقمية | أي رقم 9 أرقام فأكثر (IDs تيليجرام / هواتف) |
| سبام | `vip` `airdrop` `giveaway` `click here` `اضغط هنا` `hxxp` |
| إعادة توجيه | أي رسالة مُعاد توجيهها من قناة أخرى |
| ملصق / جيف / صوت | `sticker` `animation` `voice` — (الصور Screenshots مسموحة) |

## ⚠️ ملاحظات مهمة

1. **الصور مسموحة** — لا تُحذف (مفيدة للدعم). الصور فقط (بلا نص) تبقى.
2. **النص النظيف يبقى** — البوت يرد بالقالب ولا يحذف.
3. **كلمة عامة لا تُحذف** — مثل «تسجيل» أو «اشتراك» (حذفها كان سيخلّي رسائل شرعية تُحذف).
4. **البوت لا يحذف رسالته هو** ولا رسائل المشرفين (باستثناء السبام).
5. **معرّف المشرف** — ضع معرّفك في `config.json` (حقل `admin_id`) أو في متغير `ADMIN_ID`،
   وإلا فكل الرسائل المحذوفة ستُبَث لك.
